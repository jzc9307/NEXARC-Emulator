## [0.3.0] - 2026-11-13

Local development baseline; this version has not been published on GitHub.

- Native macOS multi-console library with imported games and cover artwork.
- Six visual save slots, recovery history and a custom paused session menu.
- Per-game settings, controller navigation and fast-forward targets from 2× to 5×.
- Handheld hardware artwork, image uploads and independent DS/3DS screen placement.
- Window presets: Small, Standard, Large, Fit to display and Custom.
- DS/3DS frame presentation and nonblocking audio changes for post-load blackouts.

Known limits: console/title compatibility varies; physical controller validation is pending. The app is locally signed, not notarized. Third-party distribution requirements must be checked before a public binary release.
